1. Verantwortlicher und Zweck

„yt2d“ ist das private Produktionswerkzeug des YouTube-Kanals „Ben & Lina – Alltag einfach erklärt“. Verantwortlich ist Torsten Strattmann, Obere Hauptstraße 12, 85354 Freising, E-Mail: BenLina_alltag@proton.me (siehe Impressum). Die Anwendung wird ausschließlich vom Kanalbetreiber für den eigenen YouTube-Kanal genutzt. Daten anderer Personen werden über die Anwendung nicht erhoben.

2. Welche Google-Daten verwendet werden

  • Zugriff auf das eigene YouTube-Konto (YouTube Data API): Hochladen eigener Videos, Setzen von Titel, Beschreibung, Tags, Thumbnail, Untertiteln, Playlists und Veröffentlichungstermin.
  • Kanalstatistiken (YouTube Analytics API): zum Beispiel Aufrufe, Wiedergabezeit, Zuschauerbindung, Abonnentengewinn und, sofern vorhanden, Umsatzkennzahlen des eigenen Kanals. Sie dienen nur dazu, die eigenen Videos zu verbessern.
  • Zugangsdaten (OAuth-Token): Sie werden ausschließlich als geschützte Umgebungsvariablen der Ausführungsumgebung gespeichert, nie im Klartext in Dateien.

3. Weitergabe und Speicherdauer

Daten werden nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben. Statistiken werden als Auswertungsdateien des Kanals aufbewahrt, solange der Kanal betrieben wird, und auf Wunsch gelöscht.

Die Nutzung von Informationen, die von Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

4. YouTube API Services

Diese Anwendung nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Der Zugriff der Anwendung kann jederzeit in den Google-Kontoeinstellungen widerrufen werden.
