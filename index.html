Ben & Lina – Alltag einfach erklärt

Ein deutschsprachiger YouTube-Kanal mit animierten Erklärvideos zu Alltagsfragen: kurz, verständlich und mit seriösen Quellen. Ben macht die typischen Alltagsfehler, Lina zeigt, wie es besser geht.

Über die Anwendung „yt2d“

„yt2d“ ist das private Produktionswerkzeug dieses Kanals. Es lädt die selbst produzierten Videos des Kanals über die offizielle YouTube Data API auf den eigenen YouTube-Kanal hoch, pflegt Titel, Beschreibungen, Untertitel und Playlists und liest die Kanalstatistiken über die YouTube Analytics API aus. Die Anwendung wird ausschließlich vom Kanalbetreiber für den eigenen Kanal genutzt und steht keinen anderen Nutzern zur Verfügung.

English: “yt2d” is the private production tool of this channel. It uploads the channel's own videos to the channel owner's own YouTube account via the YouTube Data API and reads the channel's statistics via the YouTube Analytics API. It is used only by the channel owner.
